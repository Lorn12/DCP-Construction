# Using In New Projects

When this package is copied into a new project repo:

1. Start with `AGENT_INTEGRATION_PACKAGE.md`.
2. Follow `QUICK_INTEGRATION_CHECKLIST.md`.
3. Use `ADDING_NEW_PROJECTS.md` for the full VPS onboarding path.
4. Use `PROJECT_STANDARDS.md` and `PROJECT_STRUCTURE_REQUIREMENTS.md` to prepare the app before deployment.
5. Review `LICENSING_AND_STORE_INTEGRATION.md` if the product needs portal, store, or licensing integration.

If you are also working in the VPS repo, you can cross-check `/vps/docs/integration/`, but this copied package should be enough to get started.
