# Should I Use VPS?

**Last Updated:** 2026-03-08

## Use VPS If

- Your app fits the shared Docker + Caddy model.
- You can use path-based routing on existing environment domains.
- You can follow Portal/SVC integration boundaries.

## Consider Another Platform If

- You need infrastructure/services outside this stack.
- You require strict isolated infra separate from shared VPS operations.
